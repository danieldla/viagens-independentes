# Viagens Independentes

Next.js (App Router) + TypeScript + Tailwind. Conteúdo em Markdown local.

## Adicionar um país
1. Cria `data/countries/<slug>.md` com frontmatter: `title`, `slug`, `coverImage`, `description` (opcional), `cities` (opcional).
2. Opcional: cria `data/cities/<slug>/<cidade>.md` com `title`, `slug`, `coverImage`.
3. Faz commit e push — o build seguinte gera as páginas.

Imagens em `public/images/`.
